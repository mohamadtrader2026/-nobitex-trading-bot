# Nobitex Trading Bot

ربات معامله‌گر نوبیتکس برای بازار BTC/IRT.

## وضعیت ایمنی فعلی

ربات به‌صورت پیش‌فرض در **حالت آزمایشی (TEST MODE)** اجرا می‌شود و سفارش واقعی ثبت نمی‌کند.

برای حالت واقعی باید متغیرهای محیطی زیر را آگاهانه تنظیم کنید:

- `NOBITEX_TEST_MODE=false`
- `NOBITEX_API_TOKEN`

توکن API را داخل کد یا GitHub commit قرار ندهید.

## نصب

```bash
pip install -r requirements.txt
```

## اجرا

```python
python nobitex_bot.py
```

ربات در شروع، داده‌های لازم برای میانگین‌های متحرک را جمع می‌کند و سپس سیگنال کراس MA را بررسی می‌کند.

## نکات

- فایل `bot_state.json` وضعیت معامله را نگه می‌دارد و در Git commit ذخیره نمی‌شود.
- ثبت سفارش واقعی فقط با فعال‌سازی صریح حالت واقعی امکان‌پذیر است.
- قبل از فعال‌سازی واقعی باید API Token با حداقل دسترسی لازم تنظیم شود و برداشت وجه مجاز نباشد.
- Codespaces برای اجرای دائمی 24/7 تضمین‌شده نیست؛ برای اجرای دائمی باید بعداً یک سرور مناسب تهیه و تنظیم شود.
